# Employee Salary Prediction System

## Project Overview
This project predicts employee salaries based on experience and age using Machine Learning. It uses Python and Scikit-learn to train and evaluate regression models.

## Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Joblib

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Model evaluation and comparison
- Salary prediction based on user input
- Model saving using Joblib

## Project Structure
- `Employee_salary_prediction.py` – Main project code
- `Requirement.txt` – Required libraries
- `Salary_dataset.csv` – Dataset

## How to Run
1. Install dependencies:
   `pip install -r Requirement.txt`
2. Run the project:
   `python Employee_salary_prediction.py`
